pyOPALTools
====

*pyOPALTools* is a post-processing library written in Python.

The main idea behind the library is to provide a common interface to all output formats generated by [OPAL](https://gitlab.psi.ch/OPAL/src/wikis/home) in order to analyse the
data. In the directory *pyOPALTools/opal/test/* you can find several notebooks that show the usage of the library. 

[pyOPALTools code documentation](http://amas.web.psi.ch/docs/pyOPALTools/)

## Direct Use
It is recommended to create a [Python virtual environment](https://gitlab.psi.ch/OPAL/pyOPALTools/wikis/python-virtual-environment) where you install all necessary Python packages. For the list of necessary packages see [setup.py](https://gitlab.psi.ch/OPAL/pyOPALTools/blob/master/setup.py)


In order to work properly you need to append the path of the root
directory of *pyOPALTools* to *PYTHONPATH*, i.e.
```bash
export PYTHONPATH=/path/to/root/of/pyOPALTools/:$PYTHONPATH
```
You can check if it works by importing the library in an interactive session, e.g.
```bash
>>> import opal
>>>
```

## Installation with setup.py
You can also use the *setup.py* in order to install the opal package in your [Python virtual environment](https://gitlab.psi.ch/OPAL/pyOPALTools/wikis/python-virtual-environment). For this purpose you just call
```bash
python setup.py install
```
in the root directory of *pyOPALTools*. Make sure you have the virtual environment loaded
otherwise it will be installed to your default Python.
This will install all dependencies and the opal package.
