== Scope

This note describes the minimum Breit-Wheeler physics model needed for the next
_OPALX_ benchmark.

image::breit_wheeler_qed_style_tikz.png[Breit-Wheeler scattering, width=85%] 


We follow closely the CAIN ansatz i.e. manual and source code.

The goal is not yet a full tracking implementation. The immediate target is a
host-side Monte Carlo and deterministic benchmark path that reproduces CAIN for
the process

[latexmath]
++++
\gamma + \gamma \rightarrow e^- + e^+ .
++++

The first benchmark will follow the same strategy as the linear ICS work:

- start from a fixed-geometry, unpolarized, linear process;
- implement the core event kernel in;
- validate deterministic and sampled spectra against CAIN;
- delay bunch population and tracker integration until the kernel is trusted.


== Linear Breit-Wheeler Kinematics in CAIN

CAIN's linear generator `LNBWGN` uses two incoming photons:

- a laser photon with energy latexmath:[W_1] and direction latexmath:[\mathbf{n}_1],
- a high-energy photon with energy latexmath:[W_2] and direction latexmath:[\mathbf{n}_2].

Note: in a collider setup the laser photon is also a high-energy photon.


The opening-angle dependence enters through

[latexmath]
++++
Z_0 = \mathbf{n}_1 \cdot \mathbf{n}_2 .
++++

The two-photon invariant used in CAIN is

[latexmath]
++++
S_0 = 2 W_1 W_2 (1 - Z_0) .
\label{eq:bw-cain-s0}
++++

Pair creation is kinematically allowed only if

[latexmath]
++++
S_0 \ge 4 m_e^2 .
\label{eq:bw-threshold}
++++

This threshold appears directly in `LNBWGN`:

[source,fortran]
----
S0=2*W1*W2*(1-Z0)
IF (4*M**2.GT.S0) GOTO 900
----

In a head-on geometry, latexmath:[Z_0 = -1], so the threshold reduces to

[latexmath]
++++
W_1 W_2 \ge m_e^2 .
\label{eq:bw-headon-threshold}
++++

This is the cleanest geometry for the first benchmark.


CAIN constructs the center-of-momentum boost velocity from the two incoming
photon momenta and then samples the final-state scattering variables in that
frame.

The code introduces a transformed photon energy latexmath:[W] and several
auxiliary variables:

[latexmath]
++++
W = \gamma W_1 V_R,
\qquad
X = \frac{\sqrt{W^2 - m_e^2}}{W},
\qquad
X_1 = \frac{m_e^2}{W^2 + W\sqrt{W^2 - m_e^2}} .
\label{eq:bw-cain-aux}
++++

The random variable latexmath:[Y] is used to generate the CM scattering angle
through

[latexmath]
++++
\cos\theta = 1 - 2Y .
\label{eq:bw-cain-costh}
++++

The resulting Mandelstam-like combinations in the CAIN implementation are

[latexmath]
++++
s_m = \frac{2m_e^2}{(1+X)X_1}\left[X(1-2Y)-1\right],
\qquad
u_m = -\frac{2m_e^2}{(1+X)X_1}\left[X(1-2Y)+1\right] .
\label{eq:bw-cain-sm-um}
++++

CAIN then builds the angular kernel from

[latexmath]
++++
\cos\theta_1 = 1 + 2m_e^2\left(\frac{1}{u_m} + \frac{1}{s_m}\right)
\label{eq:bw-cain-costh1}
++++

and

[latexmath]
++++
D = -\left(\frac{s_m}{u_m} + \frac{u_m}{s_m}\right) .
\label{eq:bw-cain-d}
++++

For unpolarized incoming photons, the acceptance weight reduces to the
unpolarized part of the full CAIN expression.

== Implemented OPALX Benchmark

The current _OPALX_ implementation is a host-only benchmark path in the local
`git/opalx` checkout. The relevant files are:

- `src/Physics/LinearBreitWheeler.h`
- `src/Physics/LinearBreitWheeler.cpp`
- `unit_tests/Physics/TestLinearBreitWheeler.cpp`
- `unit_tests/Physics/LinearBreitWheelerBenchmarkCommon.h`
- `unit_tests/Physics/LinearBreitWheelerBenchmark.cpp`
- `unit_tests/Physics/TestLinearBreitWheelerSpectrum.cpp`
- `~/git/cain/linear-breit-wheeler-head-on.i`
- `~/git/cain/generate-linear-breit-wheeler-results.sh`

The benchmark remains deliberately narrow:

- no tracker integration,
- no bunch population,
- no GPU path.

The validated observables are now:

- [*] electron energy spectrum,
- [*] positron energy spectrum,
- [*] electron angle spectrum,
- [*] positron angle spectrum,
- [*] joint latexmath:[E] vs. latexmath:[\theta] spectrum for the electron,
- [*] joint latexmath:[E] vs. latexmath:[\theta] spectrum for the positron.

Finite incoming-photon-beam benchmark:

- [*] electron energy spectrum with Gaussian photon-beam divergence,
- [*] positron energy spectrum with Gaussian photon-beam divergence,
- [*] electron angle spectrum with Gaussian photon-beam divergence,
- [*] positron angle spectrum with Gaussian photon-beam divergence.

The finite-photon-beam extension is still intentionally narrow:

- the high-energy photon beam is sampled only in momentum space,
- the reference beam axis is the head-on direction,
- the angular spread is Gaussian with latexmath:[\sigma_{\theta x} = \sigma_{\theta y} = 1\,\mathrm{mrad}],
- the current published benchmark keeps the photon-beam relative energy spread at zero,
- there is still no transverse position spread or laser-overlap weighting in the _OPALX_ benchmark path.


== Results of Code Comparison

The current CAIN-backed _OPALX_ benchmark compares the linear unpolarized
process `LASERQED BREITWHEELER, NPH=0` for a weak-field setup with
latexmath:[\xi = 0.25]. The benchmark observables are:

- electron energy spectrum,
- positron energy spectrum,
- electron angle spectrum,
- positron angle spectrum,
- joint latexmath:[E] vs. latexmath:[\theta] maps for electron and positron,
- and, in the extended benchmark, the same 1D observables for a finite incoming photon beam.

The first fixed-geometry comparison point uses:

- head-on geometry,
- latexmath:[E_\gamma = 0.5\,\mathrm{GeV}],
- latexmath:[\lambda_L = 1\,\mathrm{nm}],
- unpolarized photons.

With the current _OPALX_ Monte Carlo benchmark and the stored CAIN references, the
agreement is already tight.

Electron:

- [*] energy spectrum: mean-energy difference about `0.09%`, latexmath:[L_1] about `0.0179`
- [*] angle spectrum: mean-angle difference about `0.02%`, latexmath:[L_1] about `0.0176`
- [*] joint latexmath:[E]--latexmath:[\theta] map: mean-energy difference about `0.10%`, mean-angle difference about `0.02%`, latexmath:[L_1] about `0.0281`

Positron:

- [*] energy spectrum: mean-energy difference about `0.10%`, latexmath:[L_1] about `0.0160`
- [*] angle spectrum: mean-angle difference about `0.08%`, latexmath:[L_1] about `0.0173`
- [*] joint latexmath:[E]--latexmath:[\theta] map: mean-energy difference about `0.10%`, mean-angle difference about `0.08%`, latexmath:[L_1] about `0.0266`

So the present benchmark already supports both 1D and 2D CAIN-backed regression
coverage for the linear unpolarized kernel.

Finite incoming-photon-beam point:

- head-on reference geometry,
- latexmath:[E_\gamma = 0.5\,\mathrm{GeV}],
- latexmath:[\lambda_L = 1\,\mathrm{nm}],
- Gaussian photon-beam divergence with latexmath:[\sigma_{\theta x} = \sigma_{\theta y} = 1\,\mathrm{mrad}],

Finite-photon-beam agreement:

Electron:

- [*] energy spectrum: mean-energy difference about `0.12%`, latexmath:[L_1] about `0.0536`

Positron:

- [*] energy spectrum: mean-energy difference about `0.13%`, latexmath:[L_1] about `0.0535`
- [*] angle spectrum: mean-angle difference about `2.89%`, latexmath:[L_1] about `0.0696`

The angle benchmark is intentionally windowed to latexmath:[0 \le \theta \le 6\,\mathrm{mrad}], so the

== Build and Run

The full benchmark workflow is now automated from the shared `~/git/cain` workspace by:

[source,bash]
----
cd ~/git/cain
./generate-linear-breit-wheeler-results.sh \
  --opalx-build ~/git/opalx/build_openmp
----

This script:

- runs the CAIN deck `~/git/cain/linear-breit-wheeler-head-on.i`,
- regenerates the stored CAIN histogram references in `~/git/opalx/unit_tests/Physics/data`,
- runs the OPALX benchmark executable `LinearBreitWheelerBenchmark`,
- regenerates the 1D and 2D comparison plots in `~/git/cain/reference-data`.

The script expects:

- a built OPALX benchmark executable in the supplied build directory,
- a CAIN executable at `~/git/cain/CAIN-build/cain`, unless overridden by `--cain-bin`.

The relevant unit-test targets are:

[source,bash]
----
cmake --build ~/git/opalx/build_openmp \
  --target TestLinearBreitWheeler TestLinearBreitWheelerSpectrum LinearBreitWheelerBenchmark -j4

~/git/opalx/build_openmp/unit_tests/Physics/TestLinearBreitWheeler
~/git/opalx/build_openmp/unit_tests/Physics/TestLinearBreitWheelerSpectrum
----

== CAIN Structure


CAIN separates Breit-Wheeler physics into three layers.

.Input and model selection
- `LASERQED BREITWHEELER` is parsed in
  https://github.com/cfruhling2/CAIN/blob/main/src/rdlqed.f[`src/rdlqed.f`].
- `NPH = 0` selects the linear Breit-Wheeler model.
- `NPH >= 1` selects the nonlinear model.

.Runtime driver
- The laser-particle loop is handled by
  https://github.com/cfruhling2/CAIN/blob/main/src/lsrqedbw.f[`src/lsrqedbw.f`].
- Local laser geometry and power density are obtained from `LSRGEO`.
- The linear event generator is `LNBWGN`.
- The nonlinear event generator is `NLBWGN`.
- If an event happens, the produced electron and positron are inserted by
  `LBWEVENT`.

.Event generation
- Linear Breit-Wheeler:
  https://github.com/cfruhling2/CAIN/blob/main/src/lnbwgn.f[`src/lnbwgn.f`]
- Nonlinear Breit-Wheeler:
  https://github.com/cfruhling2/CAIN/blob/main/src/nlbwgn.f[`src/nlbwgn.f`]
- Weighted particle insertion:
  https://github.com/cfruhling2/CAIN/blob/main/src/lbwevent.f[`src/lbwevent.f`]

For the first _OPALX_ benchmark only the linear event kernel is needed.
