= Gamma-Gamma Physics Notes for OPALX
:toc:
:toclevels: 3
:sectnums:
:stem: latexmath
:docinfo: shared

This note collects the minimal physics model and benchmarks used while adding
laser and photon functionality to _OPALX_.

The current document starts with the simplest linear inverse-Compton benchmark:
an electron beam hit by a laser pulse under a crossing angle of 90 degrees.
This is the first deterministic unit-test baseline used in the source tree.

* link:linear-compton-benchmark.html[Linear Compton Benchmark]
* `cain-linear-compton-90deg.i`: CAIN input deck for the fixed 90 degree case
* `plot_cain_beam.py`: parser, histogram, and plot helper for CAIN `WRITE BEAM` output
* `plot_linear_compton_comparison.py`: overlay plot for the stored CAIN and OPALX weak-field spectra
* `reference-data/`: stored weak-field CAIN and OPALX spectrum CSV files
